# SSRS Basics - Week 4

SQL Server Reporting Services (SSRS) is useful for structured, paginated reports where the output must print or export consistently.

## Concepts reviewed
- Data source: connection to the database.
- Dataset: query that provides report data.
- Parameters: values users can select, such as month or region.
- Tablix: flexible table/matrix reporting object.
- Expressions: calculations and display rules.
- Export: PDF, Excel and other formats.

## Example use case
A monthly service-request detail report with parameters for Region and Status, including every request row and a total count.

## Difference from Power BI
Power BI is strong for interactive analysis. SSRS is strong for fixed-layout, detailed and printable reporting.
