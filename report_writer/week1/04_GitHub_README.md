# Weekly IT Skills Portfolio

This repository is used to organise practical learning evidence.

## Folder structure
- `week-01-foundations/` - role research, Excel and Power BI notes
- `sql-practice/` - SQL scripts and query experiments
- `data/` - small practice datasets
- `diagrams/` - process and reporting-flow diagrams
- `documentation/` - reflections and project notes

## Git workflow practised
1. Create or edit a file locally.
2. Review the changed file.
3. Stage the change.
4. Commit with a meaningful message.
5. Push to the remote repository.

Example commit message: `docs: add Week 1 learning plan`
