# Power BI Starter Notes - Week 1

## Main areas explored
- **Get Data:** connect to Excel/CSV and other sources.
- **Power Query:** inspect data types and transform data before loading.
- **Model view:** understand tables and relationships.
- **Report view:** build charts, cards, tables and slicers.

## Practice scenario
A small service-ticket dataset can be used to answer:
1. How many tickets were opened?
2. Which category has the highest volume?
3. How many tickets remain open?
4. What is the average resolution time?

## Key lesson
Choose a visual because it answers a question, not because it looks impressive.
