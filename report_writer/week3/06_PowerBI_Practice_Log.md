# Week 3 Power BI Practice Log

## Focus
Use the cleaned service-request data rather than the raw file.

## Checks before building visuals
- Confirm date column is a Date type.
- Confirm HandlingMinutes is numeric.
- Standardise `Closed`, `Open` and `In Progress` labels.
- Confirm one row represents one request.

## Report ideas
- Requests by day
- Requests by type
- Open requests by region
- Average handling minutes
- Detail table for unresolved requests

## Reflection
The same visual can produce different totals if duplicates or inconsistent status values remain in the source, so data-quality checks should be documented.
